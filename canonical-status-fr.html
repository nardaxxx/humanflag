Quelle version fait foi

Lorsqu’un document est déposé sur Zenodo, le dépôt Zenodo constitue la version faisant autorité. Chaque document est identifié ici par son concept DOI, qui renvoie au dépôt courant. Les citations doivent utiliser le concept DOI.

Les copies conservées ailleurs — notamment sur ce site, SSRN ou dans tout fichier diffusé — peuvent être en retard sur le dépôt Zenodo. En cas de divergence, le dépôt Zenodo prévaut.
